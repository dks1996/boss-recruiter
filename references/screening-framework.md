# 候选人筛选与评分框架

本文件定义候选人的评分模型、等级划分、简历深度评估表与红旗信号。Step 3（初步匹配）与 Step 5（简历筛选）必须按此框架执行。

## 一、评分维度与权重

所有维度按 1-5 分打分，加权计算总分（满分 5.0）。

| 维度 | 权重 | 1 分 | 3 分 | 5 分 |
|------|------|------|------|------|
| 技能匹配度 | 25% | 必备技能基本不具备 | 具备部分必备技能 | 必备技能齐全且有深度 |
| 经验相关性 | 25% | 行业与岗位完全不相关 | 部分相关 | 同行业同岗位且有成功案例 |
| 稳定性 | 15% | 频繁跳槽（平均任期 < 1 年） | 平均任期约 2 年 | 平均任期 ≥ 3 年且有晋升 |
| 薪资匹配度 | 10% | 期望薪资超预算 30% 以上 | 在预算上下 10% 内 | 在预算内且合理 |
| 活跃度与沟通意愿 | 15% | 长期不活跃、不回复 | 近期活跃、回复正常 | 近期活跃、主动沟通、态度积极 |
| 文化契合度 | 10% | 明显与团队价值观冲突 | 无明显问题 | 与团队氛围高度契合 |

**总分计算公式**：

```
总分 = 技能×0.25 + 经验×0.25 + 稳定性×0.15 + 薪资×0.10 + 活跃度×0.15 + 文化×0.10
```

评分时必须在候选人记录中保留每个维度的单项分数与打分依据，不得只给总分。

## 二、等级划分与处理策略

| 等级 | 总分范围 | 处理策略 |
|------|----------|----------|
| A | ≥ 4.2 | 优先沟通，尽快索要简历，建议进入面试 |
| B | 3.5 - 4.19 | 进入沟通，核实关键疑点后决定是否推荐 |
| C | 2.8 - 3.49 | 列入备选，暂不主动沟通 |
| D | < 2.8 | 淘汰，记录淘汰原因 |

## 三、硬性门槛一票否决

以下情况无论总分多少，直接判为 D 级淘汰，并在记录中写明原因：

- 学历、工作年限、必备技能中任意一项与硬性门槛差距过大且不可替代。
- 命中岗位画像卡中的排除项（如频繁跳槽、期望薪资远超预算）。
- 简历或沟通中存在明显造假、前后矛盾。

## 四、简历深度评估表

收到简历后，逐项填写下表，用它修正 Step 3 的初步评分：

| 评估项 | 评估要点 | 结论 |
|--------|----------|------|
| 工作经历 | 公司背景、任职时间、岗位职责是否真实匹配 | [填写] |
| 项目经验 | 项目规模、本人角色、成果是否可量化 | [填写] |
| 技能深度 | 必备技能是否只是罗列，是否有实际应用证据 | [填写] |
| 职业发展 | 晋升路径是否清晰，跳槽是否有合理解释 | [填写] |
| 薪资期望 | 是否与预算匹配，是否可谈 | [填写] |
| 到岗时间 | 是否满足用人紧急度 | [填写] |
| 待核实问题 | 简历中模糊或存疑之处 | [填写] |

## 五、红旗信号（出现即标注并谨慎推荐）

- 工作经历时间重叠或存在无法解释的空档期。
- 频繁跳槽（近 3 年换过 3 份以上工作）。
- 简历描述大量使用模糊词汇、缺乏具体成果数据。
- 期望薪资明显高于岗位预算且态度强硬。
- 沟通中回避关键问题、回复含糊或前后矛盾。
- 对上一家公司/上级有大量负面评价且缺乏客观反思。

## 六、推荐结论映射

| 结论 | 适用条件 |
|------|----------|
| 强烈推荐面试 | A 级且简历评估无红旗 |
| 推荐面试 | A/B 级，存在少量待核实问题但不影响核心判断 |
| 备选观察 | C 级，或 B 级但有明显待核实疑点 |
| 暂不推荐 | D 级，或命中硬性门槛否决项 |

每条结论都必须附带一句具体理由，禁止只写等级或分数。
